IT Helpdesk Agent

An AI agent for a fictional company, Northwind. Describe an IT problem and it troubleshoots with you. If it can't fix it, it opens a ticket for a technician.

It can use three tools: search the knowledge base, check for outages, and create a ticket. Tickets go to the same database as the Support Ticket Dashboard.

Agent
Hi, I'm the Northwind IT helpdesk. What's going on?
Try: My VPN won't connect from home · I clicked a link in a weird email · The printer on floor 2 isn't working

Demo with a fictional company. Don't enter real passwords or personal info. Limited to a few messages per minute.
